# Students Management System

Students Management System is a web application built on ASP .NET MVC and Razor Pages providing CRUD operations for Student, Group, and Course entities, with appropriate relationships between them and a user-friendly web interface for data display.

## Key Features

- **CRUD Operations:** Manage Student, Group, and Course entities.
- **Entity Relationships:** Maintain appropriate relationships between entities.
- **Web Interface:** User-friendly interface for data display.

## Patterns and technologies
- **ASP .NET MVC**
- **Razor Pages**
- **MVC (Model-View-Controller) Architecture**
- **Generic Repository Pattern**
- **Unit of Work Pattern**
- **Service Pattern**
- **AutoMapper**
- **NUnit**
- **Entity Framework**
- **Microsoft SQL Server Express**
